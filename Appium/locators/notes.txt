IMP -->> XPath
    XPath is a syntax for finding the element on a mobile screen or web page
    There are Two types of XPath
    1> Absolute XPath :-> It uses a complete root path to the required MobileElement path
        ex :-> /hierarchy/android.widget.FrameLayout/android.widget.LinearLayout
            a> '/' Finding the element inside the parent element
            b> '//' Finding the child or nested-child element inside the parent element
    2> Relative XPath
        --> It uses the direct path of a child element in  parent, Using (id,className,attribute values sub-string , etc) to perform action on It

        i> Ex: //tag[@attribute='value']
            //android.widget.EditText[@text='ENTER SOME VALUE']
